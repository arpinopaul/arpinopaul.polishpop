POLISH POP! v13 — IPHONE INSTALLATION

1. Upload index.html, manifest.webmanifest, sw.js, icon-192.png and icon-512.png to an HTTPS static website (for example GitHub Pages). Keep all five files together in the site root.
2. Open the HTTPS address in Safari on the iPhone.
3. Tap Share (sometimes found under the Page Menu), Add to Home Screen, enable Open as Web App if shown, then Add.
4. Open Polish Pop! from its new Home Screen icon. Once opened online and cached, the main game should also be available offline.

GITHUB PAGES EXAMPLE
- Make a repository and upload the five site files.
- Repository Settings > Pages > Build and deployment > Deploy from a branch; choose main and /(root); Save.
- Visit the GitHub Pages HTTPS link shown in Settings > Pages.

IMPORTANT
- This is an installable web app, not an Apple App Store native app.
- Progress uses browser local storage. Switching browser/site URL, deleting site data or switching between local HTML and hosted site may create separate saves. Export a gallery backup before moving devices or clearing browsing data.
- The standalone HTML is for quick local testing, not reliable iOS Home Screen installation.
